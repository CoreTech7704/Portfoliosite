# 🌐 Portfolio Website

A modern, responsive portfolio website built to showcase my projects, skills, and experience.
Designed with a focus on clean UI, smooth animations, and performance.

This portfolio serves as a central place to explore my work, learn about my technical background, and get in touch.



## ✨ Highlights

- 🎨 Clean, dark-themed modern UI  
- 📱 Fully responsive (mobile, tablet, desktop)  
- ⚡ Fast performance and optimized assets  
- 🎬 Smooth animations & transitions  
- 🧭 Simple, intuitive navigation  
- 📂 Project showcase with descriptions  
- 📬 Contact section for easy reach  
- 🛠️ Tech Stack

## ⚙️ Installation & Setup  
1️⃣ Clone the repository
```bash
git clone https://github.com/CoreTech7704/Portfoliosite.git
cd Portfoliosite
```
2️⃣ Install dependencies
```bash
npm install
```

3️⃣ Run locally
```bash
npm run dev
```

Open in browser:
http://localhost:5173
